# V7 — исправление «Аккаунт найден, но профиль не привязан»

Исправлено для старых пользователей, у которых аккаунт существует в Supabase Auth,
но в `public.nexus_users` нет профиля с `authUserId`.

`nexus_get_my_profile()` теперь безопасно создаёт только профиль текущего
авторизованного пользователя, если его нет. Пароль по-прежнему проверяет только
Supabase Auth.

После установки достаточно выйти и снова войти по старому логину/паролю.
