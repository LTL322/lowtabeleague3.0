# V2.4 — Twitch + аккаунты + роли

- В поле трансляции можно вставлять `https://www.twitch.tv/ИМЯ_КАНАЛА`.
- Сайт сам превращает ссылку в Twitch player с обязательным `parent` текущего домена.
- Сохранена поддержка YouTube.
- Twitch iframe разрешён в CSP.
- Стрим хранится через общий state Supabase, поэтому сохранённая админом ссылка доступна посетителям после синхронизации.
- Вход по логину и паролю больше не зависит от локального списка пользователей: username разрешается через серверный RPC, пароль проверяет Supabase Auth.
- Только Глава может менять `nexus_users` целиком и управлять ролями; Админ сохраняет контентные права.
