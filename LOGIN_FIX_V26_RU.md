# V2.6 — вход по логину и паролю

Исправлено:
- после выхода пользователь снова может войти по своему логину и паролю;
- логин (username) разрешается серверным RPC `nexus_resolve_login`;
- пароль никогда не сравнивается в JavaScript или базе проекта — его проверяет Supabase Auth;
- вход по email также сохраняется;
- неверные данные дают единое сообщение «Неверный логин или пароль».

ВАЖНО:
После обновления проекта один раз выполните добавленный SQL-блок
`nexus_resolve_login` из `schema_v3_secure.sql` в Supabase SQL Editor.
Без этого username-вход не будет работать.
