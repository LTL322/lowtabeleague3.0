# SQL V3.1 — полный повторно запускаемый файл

Этот файл можно запускать повторно.

Исправлено главное:
- перед созданием Storage-политик удаляются И старые, И новые имена политик;
- `ltl_media_update_staff` и `ltl_media_delete_staff` больше не вызывают ошибку `already exists`;
- `nexus_resolve_login` создаётся через `create or replace`;
- trigger регистрации пересоздаётся безопасно;
- данные пользователей не удаляются.

После запуска весь SQL должен завершиться без ошибки `policy already exists`.
