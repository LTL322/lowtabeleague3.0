# LTL SECURE V5

## Что исправлено

- Исправлена регистрация: в предыдущей V4 поле `regEmail` использовалось в JavaScript, но отсутствовало в HTML-форме. Из-за этого регистрация останавливалась на проверке обязательных полей.
- В форму регистрации добавлено поле Email.
- Исправлено сообщение об ошибке — вместо системного `alert` ошибка показывается в форме.
- Добавлена проверка корректного формата email.
- Серверный trigger Supabase сохранён для безопасного создания профиля.
- Trigger теперь также умеет обрабатывать пользователей, созданных вручную через Supabase Dashboard: если `username` не передан, используется безопасное имя из email.

## Установка

1. Загрузите содержимое этой папки в GitHub.
2. В Supabase SQL Editor выполните `schema_v3_secure.sql` целиком.
3. В Supabase Authentication → URL Configuration укажите URL GitHub Pages в Site URL и Redirect URLs.
4. Откройте сайт и зарегистрируйте пользователя с никнеймом, email и паролем.
