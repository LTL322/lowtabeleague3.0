# V2.3 — дизайн исправлен

Причина проблемы: дизайн зависел от inline CSS/JS, а в некоторых окружениях CSP блокировал inline-ресурсы.

Изменения:
- весь встроенный CSS вынесен в `styles.css`;
- встроенный JavaScript вынесен в `app1.js` и `app2.js`;
- CSP теперь не требует `unsafe-inline`;
- визуальная часть исходного сайта сохранена без переделки дизайна;
- security-настройки и возможность смены аватарок сохранены.
