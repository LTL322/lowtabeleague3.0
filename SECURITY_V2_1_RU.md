# Security V2.1

Изменение этой версии:
- Обычным авторизованным пользователям запрещена загрузка произвольных файлов.
- Сохранена возможность менять аватар: загрузка разрешена только в `avatars/` и только для PNG/JPG/JPEG/WEBP с безопасным именем.
- Администраторы/главы сохраняют возможность загружать медиа согласно staff-политике.
- Ограничения UPDATE/DELETE для media сохранены.
- Перед продакшеном рекомендуется проверить, что клиент действительно загружает аватары в `avatars/`.
