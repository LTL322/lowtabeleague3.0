# LTL V8 — постоянная авторизация

Исправлено:
- вход не сбрасывается при обновлении страницы;
- Supabase Auth использует persistent session + auto refresh;
- профиль загружается с повторными попытками;
- временная ошибка RPC профиля больше не вызывает `signOut()`;
- `SIGNED_IN`, `INITIAL_SESSION` и `TOKEN_REFRESHED` синхронизируют интерфейс;
- регистрация не уничтожает Auth-сессию из-за временной задержки создания профиля;
- обычный `signOut()` выполняется только при явном выходе пользователя.

Важно: не удаляйте данные `auth.users` и не вызывайте `signOut()` из собственного кода при перезагрузке.
