# LTL V9 — исправленный вход и восстановление профиля

Исправлено:
- вход по логину и паролю после выхода;
- сохранение Auth-сессии после F5/обновления;
- автоматическое восстановление старых профилей, у которых отсутствует authUserId;
- восстановление профиля по совпадающему email;
- существующая роль профиля сохраняется, клиент не может выдать себе права;
- регистрация новых пользователей сохраняется;
- при временной ошибке профиля сайт не делает signOut.
