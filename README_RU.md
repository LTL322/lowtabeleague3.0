# LTL — чистая финальная сборка

## В проекте
- `index.html` — сайт
- `styles.css` — дизайн
- `app1.js`, `app2.js` — функциональность
- `supabase-config.js` — подключение Supabase
- `schema_v3_secure.sql` — актуальная SQL-схема
- `vercel.json` — заголовки безопасности
- `cs-go-flashbang.mp3` — звуковой ресурс

## Supabase
Запусти `schema_v3_secure.sql` целиком в SQL Editor.
Файл построен на исходной рабочей схеме и сделан повторно запускаемым:
существующие Storage-политики удаляются перед созданием.

## Вход
Пользователь входит по логину и паролю.
Логин разрешается через `nexus_resolve_login`, а пароль проверяется только Supabase Auth.

## Аватары
Обычный пользователь может загрузить/обновить/удалить только свой аватар.
Администратор/Глава сохраняют полный доступ к медиа.

## Twitch
Поддержка Twitch и существующая функция трансляций сохранены.
