# V6 — исправлен вход по логину

Исправлена причина сообщения «Профиль пользователя не найден».

Резолвер логина теперь ищет существующего пользователя:
- в metadata Supabase Auth;
- по ключу профиля в `nexus_users`;
- по полю `username` профиля;
- и использует сохранённый email профиля.

Это особенно важно для аккаунтов, созданных до установки последнего триггера.

Пароль по-прежнему проверяется только Supabase Auth.

SQL можно запускать поверх текущей схемы: функция создаётся через CREATE OR REPLACE.
