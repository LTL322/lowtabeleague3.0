# V4 — исправлен вход и сохранены сетки BO

## Вход
Исправлен поиск пользователя по логину. `nexus_resolve_login` теперь ищет username:
- в `auth.users.raw_user_meta_data`;
- в `public.nexus_users` по `authUserId`/username.

Пароль по-прежнему проверяет только Supabase Auth.

## Сетки BO
Сохранён прежний формат:
- обычные матчи сетки — BO3;
- гранд-финал — BO5.

Не меняйте формат вручную в JS.

## Важно
После обновления проекта один раз запустите `schema_v3_secure.sql` из этого архива в Supabase SQL Editor.
Не смешивайте его с фрагментами старых SQL-файлов.
